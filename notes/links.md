# JAX libraries
Many interesting JAX projects/libraries can be found [here](https://github.com/n2cholas/awesome-jax).
In this page, I list the ones that are more cosmology and computation focused.

## Comoslogy focused (in no particular order)

- [jax-cosmo](https://github.com/DifferentiableUniverseInitiative/jax_cosmo) ― Analytical cosmology related observables
- [DISCO-DJ](https://github.com/cosmo-sims/DISCO-DJ) ― DIfferentiable Simulations for COsmology - Done with Jax
- [DISCO-EB](https://github.com/ohahn/DISCO-EB) ― Differentiable linear Einstein-Boltzmann solver (part of DISCO-DJ)
- [PyBird](https://github.com/pierrexyz/pybird) ― Biased tracers in redshift space
- [Cosmologix](https://lemaitre.pages.in2p3.fr/cosmologix/home.html) ― Cosmological distances in FLRW metric
- [candl](https://github.com/Lbalkenhol/candl) ― CMB & lensing analysis
- [JAX-GalSim](https://github.com/GalSim-developers/JAX-GalSim) ― Partial JAX reimplementation of [GalSim](https://github.com/galsim-developers/galsim)
- [Herculens](https://github.com/Herculens/herculens) ― Analysis of strong lensing imaging data
- [JaxPM](https://github.com/DifferentiableUniverseInitiative/JaxPM) ― Cosmological Particle-Mesh N-body Solver
- [pmwd](https://github.com/eelregit/pmwd) ― Particle mesh with derivatives
- [DiffHydro](https://github.com/bhorowitz/DiffHydro_public) ― Hydrodynamics framework for astrophysical simulations

## Tools
General tools for use in JAX.

- [interpax](https://interpax.readthedocs.io/en/latest/) ― Interpolation and function approximation
- [quadax](https://quadax.readthedocs.io/en/latest/) ― Numerical quadrature and integration
- [s2fft](https://github.com/astro-informatics/s2fft) ― Spherical-harmonic and Wigner transforms
- [diffrax](https://github.com/patrick-kidger/diffrax) ― Numerical differential equation solvers
- [lineax](https://github.com/patrick-kidger/lineax) ― Linear solver
- [BlackJAX](https://github.com/blackjax-devs/blackjax) ― Sampler
- [PySR](https://github.com/astroautomata/PySR) ― Symbolic expression optimization
- [NumPyro](https://github.com/pyro-ppl/numpyro) ― Probabilistic programming
- [sparsejac](https://github.com/mfschubert/sparsejac) ― Sparse jacobian computation
